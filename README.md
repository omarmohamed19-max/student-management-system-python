# 🎓 Student Management System (Python)

A comprehensive console-based application designed to manage student records and academic performance. This project was developed as a practical application of core Python programming concepts during my AI training journey.

## 🚀 Key Features
- **Dynamic Data Entry:** Allows users to input information for multiple students including Name, Age, Department, and Grade.
- **Automated Grading Logic:** Features a robust classification system to determine grades (A, B, C, D, F) based on numerical scores.
- **Smart Data Structures:**
  - **Lists:** Used for managing dynamic course offerings and student objects.
  - **Tuples:** Used for immutable data like study days.
  - **Sets:** Demonstrated for automatic duplicate removal of unique system identifiers.
  - **Dictionaries:** Utilized to store structured student profiles for easy retrieval.
- **Statistical Dashboard:** Automatically calculates total students, pass/fail counts, highest/lowest scores, and class averages.
- **Input Validation:** Prevents system errors by enforcing valid range checks for grades and inputs.

## 🛠️ Concepts Demonstrated
- Control Flow (while loops, if-elif-else conditions)
- Data aggregation and mathematical operations
- Input/Output formatting
- Basic error handling

## 💻 How to Use
1. Ensure you have Python installed.
2. Run the `main.py` file.
3. Follow the on-screen prompts to manage student data and view the final analytical report.
